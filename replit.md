# DailyHaid Calculator

A React + Vite web app for Islamic jurisprudence-based menstrual cycle (Haid/Nifas) analysis, built in Indonesian.

## Stack
- **Frontend:** React 19, Vite 8, Tailwind CSS
- **Icons:** lucide-react
- **Mobile:** Capacitor (Android)

## Running the app
```
npm run dev
```
The dev server starts on port 5000. The workflow "Start application" runs this automatically.

## Build
```
npm run build
```
Output goes to `dist/`, which Capacitor uses as the Android webDir.
